01  ·  problem

Video dataset curation has a consent problem.

YouTube's rate limits make dataset-scale download infeasible for academic groups. Bluesky hosts only short videos, and its users never consented to AI use. The closest things to a solution don't fit the gap.

Spawning's "Do Not Train" registry is opt-out only — 80M URLs honored on goodwill, applied to data that already left.

Sony's FHIBE (Nature, 2025) is the right idea executed on images: ~10,000 frames, centrally curated, with revocable informed consent. Beautiful, but small, and not video.

Mozilla Common Voice is the gold-standard opt-in crowdsourced dataset — but for audio, with no per-contribution cryptographic provenance.

The intersection — federated, video, consent-first, cryptographically signed — is empty. ConsentVid fills it.

02  ·  how it works

Three parties, one open protocol.

Every record lives in the contributor's own ATproto repository, signed by their repo key. There is no central database we control. Revocation is a record deletion. Storage is decoupled from metadata.

contributor

Sign consent.

Register a clip and a granular consent receipt on your own PDS — purpose × model class × modality × expiry × revocable. Your repo key signs both records.

appview

Index the firehose.

An AppView subscribes to ATproto Jetstream and persists every org.consentvid.* record into SQLite. Deletions mark consent revoked in real time.

researcher

Cite signed receipts.

Export a Croissant-RAI dataset manifest. Each FileObject embeds the AT-URI of its signed consent receipt. Re-sync revocations before each training run.

05  ·  why now

The substrate finally exists.

Aug 2026

EU AI Act, Art. 53

GPAI providers must publish training-data summaries including rights-holder opt-outs. ConsentVid is compliance infrastructure — signed, machine-readable, auditable.

May 2025

C2PA v2.2

Added video provenance and AI-training-consent assertions. Sony shipped a C2PA video camera; OpenAI committed Sora outputs. The standard finally meets the format.

Mar 2025

ATproto Discussion #3617

The community proposed "User Intents for Data Reuse." Active, no implementation as of April 2026. ConsentVid ships a concrete, opinionated answer.

06  ·  roadmap

What gets built next.

Q3 2026

Lexicon hosting at consentvid.org. First 100 contributors.

Resolvable lexicons under /lexicons; hosted Croissant manifests per contributor; web uploader for non-CLI users; targeted contributor outreach (egocentric video, sign language, instructional). Move from validate: false to schema-validated records.

Q4 2026

Storage and transcoding pipeline.

Cloudflare R2 storage backend (built; awaiting credentials). PeerTube-based transcoding for HLS delivery. C2PA manifest embedded in the file at register time, so consent travels with the bytes after copying.

2027

Federated AppView. Revocation feed library.

Pluggable AppView that any researcher can run independently. consentvid-loader Python library for dataset consumers — a single call before each training run re-syncs revocations and verifies signatures.
